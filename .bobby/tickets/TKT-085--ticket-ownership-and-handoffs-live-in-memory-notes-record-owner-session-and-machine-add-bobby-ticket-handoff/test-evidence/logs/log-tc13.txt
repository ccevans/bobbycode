16:- Taking a ticket: `bobby ticket assign <ID> <agent> --session "<session name>"` records owner.session, this machine and the time.
17:- Handing it on: `bobby ticket handoff <ID> --to "<session>" [--machine <computer>]`. The first run writes the six-section template into the ticket's progress.md. Fill every section (Where it stopped, Branch and commit, Unpushed patches, Resources held, Open decisions for the human, Next step; write "none" where nothing applies) and run it again. It refuses placeholders, sets the owner and commits the ticket.
