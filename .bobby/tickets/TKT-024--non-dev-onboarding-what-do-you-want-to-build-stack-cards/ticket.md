## Description

Everything in the app assumes you already have a repo, a terminal, and know
what a ticket is. The pitch — 'a full software team' — is most valuable to
someone who does not.

Add an onboarding path: 'What do you want to build?' plus stack cards, ending
in a real project the app can drive. Depends on createProject being extracted
(TKT-025).

## Acceptance Criteria

- [ ] A new user can go from an idea to a running project inside the app
- [ ] Stack choice is presented as cards, not as a config file
- [ ] The path ends on Home with a real first ticket and a next action
- [ ] Nothing in the flow requires the terminal
